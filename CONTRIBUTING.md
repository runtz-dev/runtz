## Checks

Run these before opening a pull request:

```bash
cd engine && go test ./...
cd ../frontend && npm run lint && npm run build
```

Or from the repository root, with make:

```bash
make test
```

## Project Layout

- `engine/`: Go backend engine.
- `frontend/`: Next.js web platform.
- `helm/`: Helm chart for Kubernetes deployments.
- `scripts/`: release and maintenance scripts.

The scanner CLI lives in [runtz-dev/runtz-cli](https://github.com/runtz-dev/runtz-cli)
and the MCP server in [runtz-dev/runtz-mcp](https://github.com/runtz-dev/runtz-mcp).

## Working with AI agents

Pull requests opened by AI coding agents (Claude, Codex, ...) are welcome and
follow the same rules as human contributions. If you use an agent:

- Branches come off `dev` and target `dev`; only release promotion
  flows `dev → main`. See [AGENTS.md](AGENTS.md) for the full workflow.
- Fill the "Generated by" section of the pull request template.
- Never let an agent commit secrets, tokens or personal endpoints — the reviewer
  is accountable for the diff.

## Reporting security issues

Do not open public issues for vulnerabilities — see [SECURITY.md](SECURITY.md).
